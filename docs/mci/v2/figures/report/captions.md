# Phase 4 report figures (MCI loan v2): captions

Each file in this folder: a one-line Persian caption and its source results file. Generated by `dashboard/report_figures.py`; the dashboard screenshots by `dashboard/report_screens.mjs`.

- **Charts:** 16 cm wide (1,890 px at 300 dpi). Font: B Nazanin for Persian script; ASCII (Latin letters, ASCII digits, punctuation) from Times New Roman, as in Word; the Persian percent sign and separators from Vazirmatn; glyphs none of them has from DejaVu Sans. No in-image title or footer; the caption carries both.
- **Screenshots:** 1,600 px wide, the dashboard in its light theme, each page as it opens (run 1 where the page has a run selector).
- **The note the footers carried**, for the report's text: سازمان‌ها شبیه‌سازی شده‌اند: شرکا نقش‌هایی عمومی‌اند، تعریف‌شده روی مجموعه‌دادهٔ عمومی Kaggle Home Credit Default Risk؛ دادهٔ هیچ شرکتی، از جمله همراه اول، به کار نرفته است.
