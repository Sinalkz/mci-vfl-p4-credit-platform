# Electricity (thesis), loan v1 and loan v2: the three instances side by side

Generated by `scenarios/mci_loan/v2/comparison2.py` from `results/mci_loan/v2/comparison/scenario-comparison.json`, which collects the three instances' result files (listed under `sources` there); do not edit by hand. Generated on commit `0758274`. Mean ± SD over 10 seeds unless stated.

**Read with care.** The architecture, contracts, circuit, key, model configuration and protocol are identical; the data, the label and the roles are not.
- **Electricity** predicts 5 tariff tiers on RECS 2020 households, with the power company active.
- **Loan v1** (tag `mci-v1-bank-active`) predicts a binary default label on Kaggle Home Credit Default Risk applicants, with the Bank active. **Loan v2** has the same applicants and label, with MCI active as the lender (classes 2–4 empty in both).
- **Raw F is not comparable across the label sets.** Macro-F1 averages over the classes present, so its chance level differs: about 2,000 for 5 balanced classes, about 5,000 for 2. Compare gains, rankings, stability and costs.
- **Names.** The loan organisations are generic simulated roles (`docs/mci/v2/02-preregistration.md`, section 0). Under the naming rule, the thesis's retailer and v1's e-commerce role carry no company name here.
