## Schema of every results file

**Common terms.** F = floor(10⁴ × macro-F1) on the whole test split (3,193 rows), through the circuit's integer path. FULL = F_r (the retrained FULL), FULL_J = F_j (the jointly trained fusion model), LOO_i = all but passive i (1 Bank, 2 E-commerce company, 3 Credit bureau), BASELINE = C1a = U_A = MCI alone (every passive slot zero).
